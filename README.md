# JanSathi AI

JanSathi AI is an AI-powered Government Scheme Assistant that helps people understand Indian government schemes.

## Features
- AI chatbot powered by Gemma API
- Government schemes information
- Hindi and English assistance
- Simple and user-friendly interface

## Technology Stack
- Frontend: HTML and CSS
- Backend: Python and FastAPI
- AI Model: Gemma

## Project Objective
The goal of JanSathi AI is to make information about Indian government schemes easier to understand and access.

## Future Improvements
- Add verified official government scheme data
- Improve AI responses
- Deploy the project online

## Disclaimer
Scheme eligibility and benefits should be verified through official government websites.
